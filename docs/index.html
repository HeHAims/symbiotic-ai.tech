What is done

  • Live governance interceptor engine with deterministic scoring, trace IDs, hash verification, and forensic event builder (chimera_engine_production.py).
  • Flask API with endpoints POST /cmis, GET /health, GET /openapi.json, static UI root, and upstream forwarding hook (app.py).
  • UI wired to call /cmis and render governance decision and audit info (index.html).
  • Deterministic weights file weights.json.
  • Tests added: tests/test_engine.py, tests/test_app.py, tests/conftest.py.
  • CI workflow added: .github/workflows/ci.yml.
  • Azure prep plan and runbook docs added: .azure/plan.md, README.md.
